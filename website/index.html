● 原生 macOS 防休眠与合盖保活工具 Native macOS Clamshell & Sleep Guard

让 Mac 合上盖子或关屏也保持全速运行

Keep Your Mac Awake with Lid Closed or Display Off

BudHold 基于 Swift、SwiftUI 与 IOKit 原生构建，一键锁定内核休眠与显示渲染管线。无论是合盖挂机、长时间任务计算、远程桌面连接还是物理熄屏防窥，都能稳定保活。

Built natively with Swift, SwiftUI, and IOKit, BudHold prevents idle sleep and clamshell sleep with one click while keeping the GPU display pipeline awake.

Bundle ID: com.budwk.app.budhold macOS 13.0+ (Apple Silicon & Intel) 100% 纯离线本地运行 · 零网络权限 100% Offline & Local · Zero Network Access

✨ 核心功能特性 Key Features

💻

MacBook 合盖不休眠

Clamshell Keep-Awake

支持内核级休眠锁控制（pmset SleepDisabled），即使拔掉外接显示器并合上笔记本盖子，系统依然持续高速运转，支持配置免密快捷切换。

Prevents your MacBook from sleeping when the lid is closed, even without an external monitor attached. Supports optional passwordless switching.

🖥️

防空闲睡眠与渲染保活

Idle & Display Pipeline Guard

通过 IOKit 电源断言与显示帧缓冲唤醒机制，防止关屏或合盖后系统进入空闲休眠，避免图形渲染管线挂起导致的画面黑屏。

Uses IOKit power assertions to prevent system idle sleep and keep the display framebuffer active so remote desktop sessions never go black.

🌑

物理熄屏挂机（背光 0%）

Display Blackout Mode (0%)

在开盖状态下将屏幕物理背光直接降至 0%（纯黑屏省电防窥），同时保持 GPU 渲染活跃；随时按下键盘 Esc 键或亮度键即可立即恢复屏幕亮度。

Turns physical screen backlight down to 0% for privacy and power saving while keeping the system awake. Press Esc anytime to restore brightness.

🔋

低电量安全保护与定时保活

Low-Battery Guard & Timer

内置电池低电量保护（默认电量 ≤ 20% 自动解除合盖不休眠锁），防止放入背包后积热或亏电；支持 1 / 2 / 4 / 8 / 24 小时定时或始终保持。

Automatically restores default lid sleep when running on battery below 20% to prevent overheating. Includes flexible 1h–24h timers.

🎨

状态栏常驻与深浅主题自适应

Menu Bar & Adaptive Theme

关闭窗口后自动隐藏底部 Dock 图标并常驻顶部菜单栏；支持跟随系统自动切换浅色/深色外观，以及中英双语无缝切换。

Lives quietly in your macOS menu bar with zero Dock clutter when closed. Adapts automatically to Light/Dark mode and Chinese/English.

🔒

纯本地运行 · 零数据收集

100% Local · Zero Data Collection

应用不包含任何网络请求权限，不收集、不存储、不上传任何个人隐私或设备数据，所有偏好设置仅保存在您的 Mac 本地。

Requests zero network permissions. No analytics, no tracking, and no data collection—everything stays strictly on your Mac.

BudHold 非常重视用户的隐私与数据安全。本应用是一款运行于 macOS 平台的纯本地系统电源与防休眠工具，我们郑重承诺：BudHold 不会收集、存储、共享或上传您的任何个人身份信息或设备数据。

BudHold respects and protects your privacy. BudHold is a 100% offline, local utility for macOS power management. We do not collect, store, share, or transmit any personal information or device data.

1. 零网络访问与数据收集

1. Zero Network Access & No Data Collection

  • 无网络权限：BudHold 未声明且不使用任何网络连接权限（无联网能力），应用不会向任何服务器发送请求。
  • 无第三方统计或广告 SDK：应用内未集成任何第三方分析、崩溃统计、追踪器或广告代码。
  • No Network Entitlement: BudHold does not request network access and never communicates with external servers.
  • No Third-Party SDKs: No analytics, crash reporting, tracking, or advertising SDKs are included.

2. 本地硬件状态读取说明

2. Local System Information Usage

为了在控制台界面向您展示防休眠状态并执行低电量保护，应用会通过 macOS 系统接口（IOKit）在本地实时读取以下状态：

To display current sleep guard status and provide low-battery safety protection, the app reads the following states locally via macOS APIs:

  • 当前 macOS 系统版本号与芯片架构信息；
  • 笔记本盒盖开合状态（Clamshell State）与显示器休眠状态；
  • 当前电源供电类型（外接电源 / 电池）与电池剩余电量百分比。
  • macOS version and hardware architecture;
  • MacBook lid state (clamshell open/closed) and display power state;
  • Power source (AC Power / Battery) and battery percentage for low-battery protection.

上述信息仅在您的设备内存中用于界面实时显示与本地逻辑判断，绝不会被记录或外传。

All such information is processed strictly in memory on your Mac and never leaves your device.

3. 本地偏好设置存储

3. Local Preferences

您的界面语言、保活时长、低电量保护开关等配置项仅通过 macOS 标准的 UserDefaults 保存在您的本机电脑上，您可随时卸载应用以彻底清除。

Your app settings (such as language preference, timer duration, and low-battery threshold) are stored locally on your Mac using standard macOS UserDefaults.
